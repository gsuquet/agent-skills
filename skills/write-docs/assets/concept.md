# Concept template

Replace each `<...>` field with text that follows its rule. Delete a section marked *optional*
when it does not apply; keep every other section, in this order.

````markdown
# <name of the concept>

<2 or 3 sentences: what it is, and why the reader needs to understand it>

## How it works

<the explanation, from the whole to the parts.>

## Why it works this way

<the constraints and trade-offs behind the design; link each ADR that records a decision>

## When to use it

<optional: when it fits, when it does not, and what to use instead>

## Related

- <link to the how-to and reference docs that put this concept to work>
````

- No steps: a task belongs in a how-to.
